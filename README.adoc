== Purpose

The `emf2svg` Ruby gem provides pure Ruby EMF (Enhanced Metafile) to SVG conversion capabilities.

This gem implements a complete EMF parser and SVG generator in pure Ruby, eliminating the need for native extensions or external C libraries.

== Features

* **Pure Ruby implementation**: No native compilation required, works on any Ruby platform
* **Complete EMF support**: Handles 100+ EMF record types including:
  - Drawing primitives (lines, polygons, rectangles, ellipses, arcs)
  - Path operations (begin/end path, close figure, fill/stroke)
  - Text rendering with font support
  - Bitmap embedding with multiple bit depths (1/4/8/24/32-bit)
  - Clipping regions
  - Pattern fills and hatching
  - GDI state management (pens, brushes, fonts)
  - Coordinate transformations
* **Type-safe**: RBS type definitions for better IDE support and type checking
* **Well-tested**: 214 tests with 100% pass rate on 186 reference EMF files

== Architecture

=== Core Components

The gem is built on a model-driven architecture with clear separation of concerns:

[source]
----
┌─────────────────────────────────────────────────────────────┐
│                     Emf2svg Module                          │
│  (Public API: from_file, from_binary_string)                │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                  Converter Class                            │
│  (Orchestrates parsing and SVG generation)                  │
└─────┬──────────────┬──────────────┬─────────────────────────┘
      │              │              │
      ▼              ▼              ▼
┌──────────┐  ┌──────────┐  ┌──────────────┐
│  Parser  │  │   GDI    │  │ SVG Builder  │
│          │  │ Context  │  │              │
└──────────┘  └──────────┘  └──────────────┘
      │              │              │
      │              │              │
      ▼              ▼              ▼
┌──────────┐  ┌──────────┐  ┌──────────────┐
│ BinData  │  │Transform │  │    Moxml     │
│Structures│  │          │  │              │
└──────────┘  └──────────┘  └──────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│         Record Handlers                 │
│  • Drawing  • State   • Path            │
│  • Object   • Text    • Clipping        │
│  • Bitmap                               │
└─────────────────────────────────────────┘
----

.Component descriptions
[cols="1,3"]
|===
|Component |Description

|Parser
|Parses EMF binary format using BinData, extracts header and records

|GDI Context
|Manages Graphics Device Interface state (pens, brushes, fonts, transforms, clipping)

|SVG Builder
|Generates SVG XML using Moxml library

|Record Handlers
|Process specific EMF record types and translate to SVG operations

|Transform
|Handles 2D coordinate transformations and matrix operations

|BinData Structures
|Binary structure definitions for EMF format (30+ structures)
|===

=== Data Flow

[source]
----
EMF Binary
    │
    ▼
Parser (BinData)
    │
    ├─→ Header Info (dimensions, DPI)
    │
    └─→ Records Stream
          │
          ▼
    Record Handlers ──→ GDI Context ──→ SVG Builder
          │                  │               │
          │                  │               ▼
          │                  │          SVG Output
          │                  │
          │                  └─→ State Management
          │                      (pens, brushes, fonts,
          │                       transforms, clipping)
          │
          └─→ Coordinate Transforms
----

* `chunky_png` (~> 1.4) - Bitmap processing

Development dependencies:

* `rspec` - Testing framework

== Usage

This gem provides a pure Ruby interface for EMF to SVG conversion.

There are two ways to provide EMF data to `emf2svg`.

=== Loading from file

`Emf2svg.from_file`:: Loads an EMF file directly from the filesystem.

[example]
.Example of using `Emf2svg.from_file` and exporting an SVG file
====
[source,ruby]
----
require "emf2svg"

svg_data = Emf2svg.from_file("example.emf")
File.write("output.svg", svg_data, mode: "wb")
----
====

=== Loading binary data

`Emf2svg.from_binary_string`:: Loads EMF content from binary form.

[example]
.Example of using `Emf2svg.from_binary_string` and exporting an SVG file
====
[source,ruby]
----
require "emf2svg"

emf_content = File.read("example.emf", mode: "rb")
svg_data = Emf2svg.from_binary_string(emf_content)
File.write("output.svg", svg_data, mode: "wb")
----
====

== Supported EMF Features

=== Drawing Operations

* Lines and polylines
* Polygons and multi-polygons
* Rectangles (including rounded rectangles)
* Ellipses and circles
* Arcs, chords, and pies
* Bézier curves

=== Path Operations

* Begin/End path
* Close figure
* Fill path
* Stroke path
* Stroke and fill path

=== Text Rendering

* Text output (ASCII and Unicode)
* Font selection and creation
* Text alignment
* Text justification
* Font properties (family, size, weight, style)

=== Bitmap Support

* Bitmap embedding (BitBlt, StretchBlt, StretchDIBits)
* Multiple bit depths (1, 4, 8, 24, 32-bit)
* Color palettes
* Base64-encoded data URIs in SVG

=== Graphics State

* Pen creation and selection (solid, dashed, dotted)
* Brush creation and selection (solid, hatched, pattern)
* Font creation and selection
* Stock objects (standard pens, brushes, fonts)
* Save/Restore DC state

=== Coordinate Transformations

* Set/Modify world transform
* Viewport and window extents
* Coordinate mapping modes
* Matrix operations (translate, scale, rotate)

=== Clipping

* Select clip path
* Intersect clip rectangle
* Exclude clip rectangle
* Offset clip region
* Set meta region

=== Pattern Fills

* Horizontal hatching
* Vertical hatching
* Forward diagonal hatching
* Backward diagonal hatching
* Cross hatching
* Diagonal cross hatching

== Development

=== Basic steps

After checking out the repo, run `bin/setup` to install dependencies. Then, run
`rake spec` to run the tests. You can also run `bin/console` for an interactive
prompt that will allow you to experiment.

To install this gem onto your local machine, run `bundle exec rake install`. To
release a new version, update the version number in `version.rb`, and then run
`bundle exec rake release`, which will create a git tag for the version, push
git commits and the created tag, and push the `.gem` file to
https://rubygems.org[rubygems.org].

== Performance

The pure Ruby implementation provides good performance for typical EMF files:

* Small files (< 10 KB): ~3-6 ms
* Medium files (10-100 KB): ~4-10 ms
* Large files (> 100 KB): ~10-50 ms

Performance characteristics:

* Linear scaling with file size
* Low memory overhead (< 2x file size)
* No external process spawning
* Efficient binary parsing with BinData
* Lazy evaluation where possible
